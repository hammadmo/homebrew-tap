# Homebrew tap for Hachibu and Kakeibo

```bash
brew install --cask hammadmo/tap/hachibu
```

```bash
brew install --cask hammadmo/tap/kakeibo
```

[Hachibu](https://github.com/hammadmo/hachibu) is a menu bar app that keeps
a MacBook's battery at the charge limit you choose. It needs an Apple
silicon Mac running macOS 27.

[Kakeibo](https://github.com/hammadmo/kakeibo) is a menu bar ledger of your
Claude usage: plan limits, tokens, cost, and projects. It also installs the
`kakeibo` command. It needs an Apple silicon Mac running macOS 26 and
Claude Code.
